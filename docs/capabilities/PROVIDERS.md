# Providers

A provider is an inference backend. Sentinel keeps provider behavior behind `IChatProvider` and resolves active bindings through `IModelRouter`.

Local adapters include Ollama (health, installed-model discovery, streaming and pulls), llama.cpp server, LM Studio and a generic local OpenAI-compatible endpoint. ModelService routes these through existing provider contracts; API compatibility does not certify tool calling, vision or inference for every selected model/runtime. The daemon can manage a selected local GGUF llama-server process; Ollama and LM Studio endpoints do not imply daemon ownership of their external services. The model catalog also contains cloud-provider configuration and discovery paths for OpenAI, Anthropic/Claude, Gemini, DeepSeek, Groq, and Mistral. Cloud use requires user-provided credentials and an allowed network policy.

Providers can fail independently of model selection. StaticProviderCatalog/StaticModelRouter metadata and selection are not running-provider health checks. A health response or model listing proves neither loaded model identity nor reliable inference/tool completion. OpenAI-compatible naming does not imply arbitrary endpoint configurability: current ModelService cloud-compatible routing uses the configured OpenAI credentials at the OpenAI endpoint; the generic local route has a fixed default endpoint. See [Models](MODELS.md) and [Secrets](../security/SECRETS.md).
