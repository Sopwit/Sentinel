# Keyboard Shortcuts Quick Reference

Sentinel is designed for keyboard-driven efficiency.

## Core Navigation & Global Shortcuts

| Shortcut (Linux / Windows) | Shortcut (macOS) | Action |
| :--- | :--- | :--- |
| `Ctrl+K` | `Cmd+K` | Open / Close Command Palette |
| `Ctrl+,` | `Cmd+,` | Open Application Settings |
| `Ctrl+N` | `Cmd+N` | Start New Conversation / Session |
| `Ctrl+W` | `Cmd+W` | Switch Active Workspace |
| `Ctrl+M` | `Cmd+M` | Open Memory Store Browser |
| `Ctrl+D` | `Cmd+D` | Toggle Diagnostics Panel |
| `Ctrl+Shift+L` | `Cmd+Shift+L` | Toggle Dark / Light Theme |
| `Ctrl+Q` | `Cmd+Q` | Exit Sentinel Desktop |

## Chat & Prompt Input Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Enter` | Send current message / submit prompt |
| `Shift+Enter` | Insert multiline line break in prompt editor |
| `Escape` | Dismiss modal dialog, command palette, or popover |
| `Up Arrow` (empty prompt) | Recall previous prompt from history |
