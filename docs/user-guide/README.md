# Sentinel User Guide

Welcome to the Sentinel User Guide. Sentinel is a local-first, privacy-respecting AI assistant desktop application built with Qt 6 and C++20.

## Overview

Sentinel provides a fast, native desktop companion experience designed for seamless local AI integration, document workspace awareness, and explicit privacy guarantees.

> [!NOTE]
> Primary target platform is **Fedora KDE Plasma**. Sentinel also runs portably on Linux (Ubuntu/Debian), macOS (Apple Silicon & Intel), and Windows.

## Key Highlights

- **Local-First Architecture**: Your chat history, workspace metadata, and memories stay on your machine.
- **Ollama Boundary Health Check**: Native discovery and health inspection of local Ollama instances (`http://127.0.0.1:11434`).
- **Liquid Glass Theme**: Modern matte transparent dark/light theme tailored for KDE Plasma.
- **Command Palette**: Press `Ctrl+K` (or `Cmd+K` on macOS) anywhere to quickly open commands, settings, and navigation.
