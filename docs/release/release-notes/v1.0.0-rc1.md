# Sentinel 1.0.0-rc.1 Release Notes

**Release Date:** July 30, 2026  
**Build Target:** Desktop Alpha Release Candidate 1  
**Primary Target Platform:** Fedora KDE Plasma  

---

## What's New in 1.0.0-rc.1

### 1. Ollama Provider Discovery Boundary
- Full health check integration with local Ollama service (`http://127.0.0.1:11434`).
- Automatic model catalog detection and version reporting in UI settings.

### 2. Transparent Matte Liquid Glass Interface
- Redesigned QML presentation layer built for KDE Plasma aesthetics.
- Custom dark/light mode palette with glassmorphism panels.
- Micro-animated Command Palette (`Ctrl+K`).

### 3. Decoupled Multi-Database Persistence
- Isolated SQLite stores for memory taxonomy (`memory.sqlite3`), transcript history (`chat_history.sqlite3`), and Local RAG metadata (`local_rag.sqlite3`).
- Clean separation from JSON preferences (`settings.json`).

---

## Known Constraints

- Model prompt execution remains disabled in accordance with Phase 9 boundary rules.
- Local RAG document vector search operates as local metadata indexing only in this release candidate.
