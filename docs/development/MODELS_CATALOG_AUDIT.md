# Models catalogue audit — 2026-10-08

## Findings and fixes

- Corrected DeepSeek R1 8B sources from the nonexistent Qwen variant to the official Llama variant, including its MLX conversion. Removed the unverified `mlx-community/flux1-schnell-mlx` source.
- Removed duplicate FLUX, SDXL, Kokoro and Whisper entries. The bundled catalogue now contains 47 entries: 18 text, 5 reasoning, 2 vision, 4 image, 11 video, 2 speech recognition, 2 text-to-speech, 1 embedding and 2 runtime entries.
- Shared task classification gives explicit media, embedding and vision metadata precedence over family-name guesses. Plain Phi-4 is a text model; it is no longer labelled as an explicit thinking model solely from its name. Mixed vision/reasoning models also appear in the reasoning filter. Local model inference remains a best-effort name fallback when runtime metadata is missing.
- Manual Refresh bypasses the 15-minute Hugging Face query cache. The page displays bundled catalogue validation date, remote status, last fetch time and the original 100-artifact display limit (superseded by the paginated discovery extension below). Refresh preserves the current search. Popular/Newest buttons explicitly describe Ollama ordering.
- Page activation and daemon reconnection retry catalogue loading, preventing the initial fetch from being lost before IPC connects. Catalogue loading includes all three sources; source errors are visible. HTML parse failures preserve prior results and report an error. Network catalogue requests have a 12-second timeout and ignore superseded replies.
- LM Studio cloud-only cards cannot offer local downloads. If no Hugging Face repository is known, the LM Studio action opens the actual model catalogue page rather than pretending to open a specific app download. Popularity counts are separated from file sizes.
- LM Studio SVG markup is removed from tags; common HTML character entities are decoded in descriptions and names. Model rows update when metadata changes, including categories and download availability.

## Coverage limits

The screen is a provider-independent discovery catalogue, not an exhaustive synchronized mirror of every upstream model. Bundled fallback entries update with Sentinel releases. Live Ollama, LM Studio and Hugging Face discovery now refreshes on page entry/search/manual refresh and every 15 minutes while the daemon helper is running. Hugging Face is browsed in bounded batches of 40 repositories through trusted API continuation links; displayed discovery pages contain 40 entries. The source still inspects at most 200 artifacts per repository, so very large repository trees are not an exhaustive file listing. Some metadata remains unavailable or inferred. Media catalogue entries require compatible external generation/speech pipelines; chat runtimes do not execute all listed categories. No multi-gigabyte download, exhaustive responsive-window matrix or Linux/Windows native UI certification was performed in this audit.

Primary reference: [Hugging Face Hub API](https://huggingface.co/docs/hub/api). Corrected model sources: [official DeepSeek Llama 8B](https://huggingface.co/deepseek-ai/DeepSeek-R1-Distill-Llama-8B) and [MLX conversion](https://huggingface.co/mlx-community/DeepSeek-R1-Distill-Llama-8B-4bit).


## Live discovery extension — 2026-10-08

- Added task-filtered Hugging Face discovery for text, vision, image, video, speech and embeddings; image/video filters support both text and image conditioning. Most downloaded and recently updated ordering is independent of the selected chat provider.
- Follow API `Link` continuations on demand rather than stopping at the first result batch. Continuations are restricted to HTTPS on the Hugging Face model-list API with no user information or non-default port. Cursor metadata persists with the validated query snapshot; malformed replies and network errors preserve existing metadata.
- Daemon-owned catalogue helpers refresh all three live sources every 15 minutes, obey network policy and avoid replacing active requests. Ollama and LM Studio retain atomic, versioned last-successful snapshots across restarts; timestamps distinguish the last successful fetch from a current fetch attempt. HTML sources remain dependent on upstream page structure and explicit errors are retained when parsing fails.
- Source task, updated timestamp, revision, download count, likes and gated-access notices supplement existing license, architecture, size and quantization fields. Missing values remain explicitly unreported. Non-GGUF repository cards use repository names and canonical model-card URLs rather than arbitrary file names such as `.gitattributes`.
- Added previous/next discovery controls and a wrapping toolbar. Detached visible model snapshots fix same-size page updates through QML QVariant wrappers; unchanged helper replies no longer rebuild the list. Cached the immutable generated IPC projection contract once and copied installed model-name sequences before sorting, closing an observed CPU stall during initial projection loading.
- Native macOS verification retrieved 40 task-filtered video entries (51 merged with the bundled fallback), changed visible cards between discovery pages 1 and 2, returned to page 1 and selected image-to-video with the keyboard. A deliberately unmatched public search produced the visible empty-result message, then recovered when cleared. Model details displayed real task/license/revision/date/popularity metadata, with unsupported video chat downloads disabled. A representative response was 81,633 bytes, below the 262,144-byte IPC frame limit. This measurement is not a universal guarantee for arbitrary upstream metadata.
- The final C++ changes passed all 114 CTest tests (120.02 seconds). Focused runtime and Desktop IPC tests also passed (14.41 seconds), including a new same-size-page/unchanged-snapshot regression. The final QML-only adjustment keeps Refresh available in media categories and was compiled in the Release application. Release Desktop/daemon builds and generated contract checks passed. Changed QML compiled successfully; lint remains subject to existing unqualified context-property warnings. No large model download was performed.

A continuously refreshed discovery catalogue is not an unconditional mirror of every upstream repository or a guarantee that every runtime supports every model. Availability, gated access, missing task metadata, upstream rate limits and supported inference formats remain explicit source/runtime constraints. Linux and Windows native UI behavior and a complete responsive-size matrix remain unverified in this macOS run.
