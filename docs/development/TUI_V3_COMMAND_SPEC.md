# TUI V3 command specification

Status: implementation plus bounded verification, 2026-10-09. This is a thin IPC client, not a second runtime.

`cli/crates/sentinel-tui/src/commands.rs` is the typed registry. It owns stable enum identifiers, canonical names, descriptions, aliases, argument enums, availability, security classes, backend requirements, examples and bindings. `App::command` is the exhaustive handler dispatch. Slash entry, palette and registered keyboard bindings resolve that same dispatch; contextual selection uses the existing daemon operations. Help is generated from the registry, with the editor contract alongside it. No new CLI flags or protocol commands were added.

Type `/` at the start of the composer for fuzzy discovery. Up/Down selects; Tab completes without executing; Enter on an incomplete name completes; Enter on an exact name executes after argument/availability validation. An argument-taking completion adds a space. Escape hides discovery and preserves text. Unknown names offer edit-distance suggestions then fuzzy suggestions and are never Agent tasks. Unsupported commands remain discoverable with exact refusal reasons. Disabled rows cannot dispatch.

Pasted slash text is literal, including after prompt-history recall and failed submission. Type `//text` to send `/text`. Bracketed paste never submits. A typed multiline slash command is rejected; it is not a shell script. No `!` shell execution exists.

Argument schemas: None rejects trailing arguments; OptionalText preserves text as one bounded composer string; RequiredText requires a nonempty rename up to 256 bytes; Mode accepts only chat/agent; Export accepts markdown/json/text; Index accepts a positive 1-based reference index. Command names are bounded at 64 bytes. Composer remains bounded at 65,536 bytes; IPC frame bounds still apply. Titles and queries are not shell-expanded.

Availability is checked again at dispatch: connection, session identity, idle/busy state and active operation. Selection cannot detach or cancel active work. `/exit` also refuses unsent text/references. `/archive` refuses unsent content. `/resume last` uses the first non-archived entry in the latest cached daemon list; `/sessions` refreshes it. Bare `/resume` opens the picker.

## Complete registry

Local means client-only UI. Inspect and Selection remain subject to daemon policy; WorkspaceInspect requires the filesystem gateway. SessionMutation changes conversation metadata only. Cancellation requests the daemon, never declares completion. Unsupported sends nothing. These classifications do not grant permissions.

## Operation limits

`/history` covers the current session, not global full-text history. `/settings` inspects current TUI environment and the in-memory details preference, not a persistent settings editor. `/tools`, `/permissions`, `/mcp`, `/tasks`, `/context`, `/memory` inspect fresh safe `terminal.state` subsets. `/agents` aliases `/tasks` and inspects summaries; it cannot spawn agents. `/review` aliases the existing Applied workspace evidence view, not an autonomous code review. `/clear` creates a new conversation; it does not delete history. `/export` calls the existing finite desktop action, uses daemon-controlled output paths and reports actual acceptance/result; live populated export was not exercised.
